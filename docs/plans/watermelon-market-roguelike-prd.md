# 수박수박수박박수박: 마트 노동 로그라이크 기획서

## 1. 프로젝트 개요

### 한 줄 소개

사장님의 기묘한 운영 지시를 골라, 3일간의 수박 마트 근무를 버텨내는 짧은 분류 로그라이크.

### 게임 정체성

`수박수박수박박수박`은 싱싱한 수박과 썩은 수박을 빠르게 분류하는 즉시성 있는 아케이드 게임이다. 플레이어는 스테이지 시작과 중간마다 특수 배송 상자에서 특성을 선택하고, 수박의 가치·생존 방식·위험도를 바꿔 자신만의 마트 운영 빌드를 완성한다.

단순히 높은 점수를 내는 것보다, 매판 서로 다른 운영 지시    와 특성 조합으로 다른 판단 우선순위를 경험하게 하는 것이 핵심이다.

## 2. 목표

- 브라우저에서 설치와 로그인 없이 즉시 플레이할 수 있는 웹 게임을 만든다.
- 첫 30초 안에 기본 분류 규칙과 특성 선택의 재미를 보여준다.
- 1회 플레이는 카드 선택을 포함해 약 2~4분 안에 끝난다.
- 짧은 런 안에서도 서로 다른 빌드와 재도전 동기를 만든다.
- 향후 Android와 Hive 연동을 통해 글로벌 랭킹·시즌 이벤트·운영 분석으로 확장할 수 있는 구조를 제시한다.

## 3. 핵심 경험

1. **즉시 이해**: 싱싱한 수박은 왼쪽, 썩은 수박은 오른쪽으로 보낸다.
2. **생존과 숙련**: 실수는 클레임을 소모하고, 콤보는 고득점 보상으로 작동한다.
3. **선택과 빌드**: 스테이지마다 특성을 여섯 번 선택하며 수박의 가치와 전략을 바꾼다.
4. **정산의 만족감**: 마지막에 이번 런의 특성, 성과, 직업명이 담긴 정산날 대시보드를 확인한다.

## 4. 기본 조작과 규칙

| 대상 | 조작 | 결과 |
| --- | --- | --- |
| 싱싱한 수박 | 왼쪽 버튼 또는 `←` | 올바른 분류 |
| 썩은 수박 | 오른쪽 버튼 또는 `→` | 올바른 분류 |
| 오분류 또는 시간 초과 | 없음 | 클레임 1개 소모, 콤보 초기화 |

- 시작 클레임은 3개다.
- 클레임이 모두 소진되면 해고되고 런이 종료된다.
- 쓰레기봉투와 쓰레기 수박은 기본 게임 오브젝트에서 제거한다.
- 기본 분류 방향은 특성으로 바꾸지 않는다. 특성은 점수 가치, 출현 확률, 시간, 생존 규칙을 바꾼다.

## 5. 진행 구조

### 스테이지 흐름

```text
Stage 1 시작 → 주요 특성 선택 → 진행도 50% → 보조 특성 선택
→ Stage 2 시작 → 주요 특성 선택 → 진행도 50% → 보조 특성 선택
→ Stage 3 시작 → 주요 특성 선택 → 진행도 50% → 보조 특성 선택
→ 정산날 대시보드
```

특성 선택은 매번 세 장의 카드 중 한 장을 고른다. 총 여섯 개의 특성을 보유한 상태로 런을 종료한다.

### 스테이지 정의

| 스테이지 | 테마 | 정확 분류 목표 | 난이도 |
| --- | --- | ---: | --- |
| 1. 입고 검수 | 첫 출근 | 60개 | 기본 속도와 규칙 학습 |
| 2. 폐점 세일 | 급한 재고 처리 | 80개 | 제한 시간 감소, 등장 속도 상승 |
| 3. 월말 정산 전야 | 실적 마감 | 100개 | 최고 속도, 빌드 효과 극대화 |

내부적으로는 정확 분류 횟수로 진행한다. 사용자에게는 `오늘의 납품 목표 0~100%`로 표시한다. 목표의 50%에 도달하면 보조 특성 선택이 등장한다.

### 콤보의 역할

- 콤보는 스테이지 진행 조건이 아니다.
- 올바른 분류 시 증가하며 점수 배수와 숙련 보상에 사용한다.
- 실수·시간 초과 시 0으로 초기화한다.
- 전체 런 100콤보는 고수 플레이를 위한 업적 또는 추가 정산 보너스로만 사용한다.

> 스테이지당 100콤보를 요구하지 않는다. 콤보가 끊기면 보상에 도달할 수 없는 구조는 초보 플레이어가 빌드의 재미를 경험하지 못하게 하기 때문이다.

## 6. 배송 상자와 특성 선택

### 연출

1. 스테이지 시작 또는 진행도 50%에 도달한다.
2. 레일과 타이머를 완전히 멈춘다.
3. 배송 트럭 또는 하늘에서 떨어지는 상자 애니메이션을 보여준다. 
4. 특성 카드 3장을 표시한다.
5. 한 장을 탭하면 효과를 명확한 문구와 화면 효과로 알린다.
6. 선택한 특성 효과를 적용하고 게임을 재개한다.

상자는 플레이 도중 놓칠 수 있는 상호작용 오브젝트가 아니다. 이는 모바일의 좌우 분류 조작과 충돌하고, 우연한 놓침이 불공정한 실패가 되는 문제를 막기 위함이다.

### 특성 분류

| 구분 | 선택 시점 | 역할 | 예시 |
| --- | --- | --- | --- |
| 주요 특성 | 각 스테이지 시작 | 점수의 가치와 운영 방향을 크게 바꿈 | 폐기물 수집가, 프리미엄 과일상, 과속 컨베이어 |
| 보조 특성 | 각 스테이지 진행도 50% | 생존·콤보·시너지를 보완 | 사장님 아들 낙하산, 야근 수당, 긴급 휴식 |

### 초기 특성 풀: 20개

첫 제출본은 주요 특성 10개와 보조 특성 10개를 정의한다. 주요 특성은 스테이지 시작 배송 상자에서만, 보조 특성은 스테이지 진행도 50% 배송 상자에서만 제시한다. 동일 특성의 중복 선택은 허용하지 않는다.

특성은 모두 처음부터 선택 풀에 포함한다. 영구 해금이나 플레이어 간 진행도 차이를 만들지 않으며, 각 특성의 수치와 등장 가중치는 플레이 테스트 후 조정한다.

### 주요 특성 초안

| 특성 | 구분 | 효과 | 대가/전략 |
| --- | --- | --- | --- |
| 폐기물 수집가 | 주요 | 썩은 수박 정확 분류 시 +2점 | 싱싱한 수박 기본 점수 0 |
| 프리미엄 과일상 | 주요 | 싱싱한 수박 정확 분류 시 +2점 | 썩은 수박 분류 시 콤보 감소 |
| 과속 컨베이어 | 주요 | 모든 획득 점수 ×2 | 제한 시간 20% 감소 |
| 산지 직송 계약 | 주요 | 싱싱한 수박 등장률과 보상 증가 | 썩은 수박 분류 보상 감소 |
| 야간 할인 계약 | 주요 | 썩은 수박 등장률과 보상 증가 | 싱싱한 수박 분류 보상 감소 |
| 대량 납품 계약 | 주요 | 스테이지 클리어 보너스 증가 | 해당 스테이지 목표 20% 증가 |
| 정밀 검수대 | 주요 | 높은 콤보에서 점수 배수 증가 | 실수 시 콤보 손실이 커짐 |
| 회전율 우선 | 주요 | 수박 전환 애니메이션과 등장 속도 증가 | 제한 시간 감소 |
| 품질 보증제 | 주요 | 클레임 공제 감소 | 기본 분류 보상 감소 |
| 월말 특근 | 주요 | Stage 3의 모든 보상 증가 | Stage 1·2의 점수 보상 감소 |

### 보조 특성 초안

| 특성 | 구분 | 효과 | 대가/전략 |
| --- | --- | --- | --- |
| 사장님 아들 낙하산 | 보조 | 다음 클레임 1회 무효 | 직접 점수 보너스 없음 |
| 야근 수당 | 보조 | 콤보 10 이상에서 추가 점수 | 낮은 콤보에서는 효과 없음 |
| 긴급 휴식 | 보조 | 다음 스테이지 시작 시 클레임 1개 회복 | 즉시 점수 보상 없음 |
| 반품 처리 수당 | 보조 | 클레임이 발생할 때마다 반품 스택 +1, 다음 5회 정확 분류에 스택당 추가 수당 | 실수 뒤 빠른 회복에 유리 |
| 빠른 손 수당 | 보조 | 제한 시간 절반 안에 분류하면 추가 점수 | 늦은 분류에는 효과 없음 |
| 안전모 | 보조 | 첫 시간 초과는 클레임을 소모하지 않음 | 오분류는 막지 못함 |
| 단골 고객 | 보조 | 같은 종류의 수박을 연속 분류하면 보너스 | 종류가 바뀌면 누적 초기화 |
| 재고 정리표 | 보조 | 다음 스테이지 납품 목표 15% 감소 | 현재 스테이지에는 효과 없음 |
| 성과급 봉투 | 보조 | 다음 스테이지 클리어 보너스 증가 | 현재 스테이지에는 효과 없음 |
| 초과 근무 도장 | 보조 | 스테이지 후반에 추가 점수 배수 | 초반에는 효과 없음 |

특성 선택 화면은 주요/보조 풀을 섞지 않는다. 따라서 플레이어는 매번 세 가지의 비교 가능한 운영 방향 또는 보조 전략 중 하나를 고른다.

## 7. 점수와 정산

### 점수 구성

- 올바른 분류 기본 점수
- 현재 콤보에 따른 배수 또는 추가 점수
- 특성 효과로 인한 가감점
- 스테이지 클리어 보너스
- 전체 런 100콤보 달성 보너스

점수는 내부적인 게임 계산 기준으로 유지한다. 사용자에게는 점수가 단순 숫자가 아니라 마트 근무의 성과인 `매출`과 `급여`로 해석되어 보여야 한다.

### 정산날 대시보드

세 스테이지를 완료하면 `정산날!` 화면을 표시한다. 런이 중도 종료된 경우에도 현재까지의 성과를 `중도 정산`으로 동일한 형식으로 보여준다.

- 최종 매출/점수
- 클리어 스테이지
- 최고 콤보
- 남은 클레임
- 선택한 특성 여섯 개
- 이번 런의 직업명 또는 빌드명
- 재도전 및 공유 버튼

### 근무 일지

정산날 화면은 현재 런의 이야기를 설명하는 근무 일지를 포함한다. 이전 런을 저장하는 영구 기록 시스템은 첫 제출본의 범위에서 제외한다.

```text
[근무 일지]
Stage 1  입고 검수        20 / 20 완료
Stage 2  폐점 세일        25 / 25 완료
Stage 3  월말 정산 전야    30 / 30 완료

[오늘의 운영 지시]
폐기물 수집가 · 과속 컨베이어 · 사장님 아들 낙하산
```

### 급여 명세서

점수의 출처를 급여 명세서로 보여준다. 특성이 만든 플레이 차이를 결과에서도 읽을 수 있게 하는 것이 목적이다.

```text
[급여 명세]
분류 수당          ₩12,400
콤보 수당           ₩3,200
특수 계약 수당      ₩1,500
클레임 공제          -₩600
──────────────────────
이번 근무 실수령    ₩16,500
```

| 항목 | 계산 기준 |
| --- | --- |
| 분류 수당 | 올바른 분류로 얻은 기본 점수 |
| 콤보 수당 | 최고 콤보와 콤보 관련 특성 보너스 |
| 특수 계약 수당 | 선택한 특성으로 발생한 추가 점수 |
| 클레임 공제 | 오분류·시간 초과로 소모한 클레임 |
| 실수령 | 위 항목을 합산한 이번 런의 최종 성과 |

돈은 상점에서 쓰거나 누적하는 영구 재화가 아니다. 점수를 마트 근무 성과로 표현하는 장치이며, 영구 해금이나 별도 경제 시스템을 만들지 않는다.

직업명은 특성 조합을 바탕으로 생성한다. 예: `폐기물 전문 분류원`, `과속 마트의 에이스`, `프리미엄 과일 담당자`.

## 8. 독창성 원칙

이 게임의 독창성은 새로운 조작법이 아니라, **마트의 운영 지시가 분류 대상의 가치와 생존 방식을 바꾸는 점**에 있다.

- 모든 특성은 마트 노동·사장·물류·재고라는 세계관에 연결한다.
- 숫자만 증가시키는 특성보다, 플레이어가 반기는 수박과 위험으로 느끼는 수박을 바꾸는 특성을 우선한다.
- 강력한 효과에는 명확한 대가를 둬 정답 빌드를 없앤다.
- 기본 방향 규칙은 고정해, 독창성이 불친절함으로 변하지 않도록 한다.

## 10. 구현 우선순위

1. 주요 특성 10개와 보조 특성 10개의 효과·대가·시너지 가설을 데이터로 정의한다.
2. 기존 실시간 분류 게임을 60·80·100 목표의 스테이지·클레임 구조로 전환한다.
3. Stage 1/2/3의 시작 및 진행도 50% 보상 전환을 구현한다.
4. 특성 데이터 모델과 주요/보조 카드 선택 UI를 구현한다.
5. 특성 효과가 점수·시간·클레임·스폰 정보에 반영되게 한다.
6. 정산날 대시보드에 근무 일지와 급여 명세서를 구현한다.
7. 실제 플레이에서 특성별 선택률, 런 길이, 스테이지 도달률을 확인하고 수치를 조정한다.
8. 모바일 브라우저에서 전체 런을 테스트하고, 썸네일·영상·제출 설명을 준비한다.

## 11. 성공 기준

- 첫 30초 안에 플레이어가 분류와 특성 선택을 모두 경험한다.
- 모든 런에서 총 여섯 번의 선택 기회가 제공된다.
- 각 런은 주요 특성 3개와 보조 특성 3개를 보유한 상태로 종료된다.
- 실수 후에도 남은 클레임이 있으면 런이 계속된다.
- 선택한 특성은 다음 플레이에서 명확히 체감된다.
- 3스테이지를 마치면 빌드, 근무 일지, 급여 명세서가 담긴 정산날 화면이 나타난다.
- 결과에 표시되는 돈은 영구 재화로 저장되거나 상점 기능에 사용되지 않는다.
- 게임은 브라우저에서 안정적으로 실행되며, 모바일 터치와 데스크톱 키보드를 모두 지원한다.
